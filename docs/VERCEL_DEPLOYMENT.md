# Vercel Deployment

This project deploys as two Vercel projects:

- API project: `memory-assistant-api`, root directory `apps/api`
- Web project: `memory-assistant-web`, root directory `apps/web`

The API stores account and wordbook data in Neon Postgres through `DATABASE_URL`.

## 1. API Project

Create a Vercel project with:

```text
Root Directory: apps/api
Framework Preset: Other
```

Connect Vercel Marketplace Neon Postgres to this API project. Use the pooled `DATABASE_URL` generated by Neon.

Required API environment variables:

```env
DATABASE_URL=<vercel-neon-pooled-database-url>
GOOGLE_CLIENT_ID=<google-web-oauth-client-id>
CORS_ORIGINS=https://<web-project-domain>.vercel.app,http://localhost:5173,http://127.0.0.1:5173
LOG_LEVEL=warn
AUTH_TOKEN_TTL_HOURS=168
DEBUG_IMPORT=false
DEBUG_SESSION=false
DEBUG_PROGRESS=false
DEBUG_AUTH=false
```

After deployment, verify:

```text
GET https://<api-project-domain>.vercel.app/health
```

Expected response:

```json
{"status":"ok"}
```

## 2. Web Project

Create a Vercel project with:

```text
Root Directory: apps/web
Framework Preset: Vite
```

Required web environment variables:

```env
VITE_API_BASE_URL=https://<api-project-domain>.vercel.app
VITE_GOOGLE_CLIENT_ID=<google-web-oauth-client-id>
VITE_GOOGLE_API_KEY=
VITE_GOOGLE_APP_ID=
VITE_DEBUG_IMPORT=false
VITE_DEBUG_SESSION=false
VITE_DEBUG_PROGRESS=false
```

`VITE_GOOGLE_API_KEY` and `VITE_GOOGLE_APP_ID` are only needed for Google Drive file import. They are not required for Google login.

## 3. Google OAuth

Create a Google Cloud Web OAuth Client ID.

Authorized JavaScript origins:

```text
http://localhost:5173
https://<web-project-domain>.vercel.app
```

Use the same client ID for:

```text
API: GOOGLE_CLIENT_ID
Web: VITE_GOOGLE_CLIENT_ID
```

## 4. Smoke Test

API:

```text
POST /auth/register
POST /auth/login
GET /me
POST /wordbooks
POST /wordbooks/{id}/words/batch
GET /sync/pull?sinceRevision=0
```

Web:

1. Open the deployed web URL.
2. Sign in with Google.
3. Create a wordbook and add words.
4. Refresh the page.
5. Confirm the wordbook loads from the server DB.
6. Sign in again from another browser and confirm the same data appears.

## Codex Boundary

Codex can prepare the repository, tests, deployment config, and smoke-test commands.

The user must create or approve:

- Vercel projects
- Vercel Marketplace Neon resource
- Google Cloud OAuth Client ID
- Production environment variables in Vercel
