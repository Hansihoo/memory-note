# Temporary Planning 004: 체계적 영어 암기 플랫폼 고도화 방향

## 문서 목적
- 이 문서는 개발 착수용 명세가 아니라, 제품 방향을 논의하기 위한 임시 기획 메모다.
- 현재 `암기 어시스턴트`를 단순 단어장 앱이 아니라 과학적 복습, 재미, 교재화, 협업 학습, 선생님/반 관리까지 확장할 수 있는 영어 암기 플랫폼으로 발전시키기 위한 아이디어를 모은다.
- 이 문서는 사용자의 아이디어와 외부 학습 앱/학습 과학 조사를 같이 정리한 초안이다.

## 현재 제품의 위치
- 현재 제품은 key/value 기반 암기장을 만들고, 문제와 답을 숨김/공개하며, `알고 있음`/`잘 모르겠음`으로 학습 기록을 남기는 웹 앱이다.
- Chrome 확장 프로그램은 웹페이지 우측 상단에 작은 노트형 퀴즈를 띄워, 사용자가 다른 일을 하다가도 짧게 암기 문제를 풀 수 있게 한다.
- 현재 구조는 `apps/web`, `apps/api`, `apps/extension`, `packages/core`로 나뉘어 있으며, 추후 모바일 앱에서도 공통 암기 로직을 재사용할 수 있게 열어두고 있다.

## 사용자가 잡은 고도화 방향
- 단순히 암기 단어장을 보여주는 앱이 아니라, 과학적으로 잘 외워지도록 설계된 시스템으로 만들고 싶다.
- 여러 암기 플랫폼의 좋은 아이디어를 수집해서 적용하고 싶다.
- 약간의 병맛 재미를 넣고 싶다. 예: 계속 클릭하지 않으면 앱 아이콘이 삐지거나 변하는 식.
- 단어만 외우는 것에서 끝내지 않고, 그 단어를 이용한 문장 암기로 이어가고 싶다.
- 하나의 개인 단어장을 넘어서, 체계적인 영어 암기 교재처럼 만들고 판매할 수 있는 구조를 원한다.
- 사용자가 한 달 뒤 최근 단어만 기억하고 예전 단어는 잊어버리는 문제를 해결해야 한다.
- 단기 기억과 장기 기억을 구분해, 가끔씩 예전 문제를 다시 질문해야 한다.
- 동료끼리 같이 공부하면 더 잘 외워질 수 있으므로, 함께 공부하는 흐름을 넣고 싶다.
- 같은 교재를 공부하는 사람들끼리 얼마나 공부했는지 교류할 수 있는 시스템을 만들고 싶다.
- 같은 교과를 공부하는 사람들을 자동으로 묶고, 특정 상황을 주고 영어로 질문/답변하도록 만들 수도 있다.
- 사업적으로는 반 학생들이 같이 공부하고, 선생님이 학생들이 얼마나 암기했는지 볼 수 있는 시스템도 가능하다.

## 핵심 문제 정의
- 사용자는 단어를 외웠다고 느끼지만 시간이 지나면 최근 내용만 기억하고 오래된 단어는 잊어버린다.
- 기존 단어장 앱은 단어를 저장하고 퀴즈를 내는 데 그치기 쉽다.
- 진짜 문제는 `지금 무엇을 다시 봐야 하는지`, `어떤 단어가 장기 기억으로 넘어갔는지`, `어떤 단어가 계속 무너지는지`를 앱이 대신 관리해야 한다는 점이다.
- 따라서 제품의 중심은 `단어장 관리`에서 `복습 스케줄링과 기억 상태 관리`로 이동해야 한다.

## 학습 과학에서 가져올 핵심 원리

### 1. 간격 반복
- 한 번에 몰아서 보는 것보다, 시간 간격을 두고 반복하는 것이 장기 기억에 유리하다.
- Cepeda 등의 분산 학습 메타분석은 317개 실험, 839개 평가를 검토했고, 복습 간격과 최종 기억 기간이 함께 작용한다고 정리했다.
- 제품 적용:
  - 모든 카드에 `nextReviewAt`을 둔다.
  - 새 단어는 짧은 간격으로 자주 나오고, 잘 맞히는 단어는 점점 긴 간격으로 나온다.
  - 한 달 뒤에도 예전 단어가 다시 나오도록 `오래된 단어 샘플링`을 강제한다.

### 2. 능동 회상
- 답을 보기 전에 먼저 떠올리는 과정 자체가 기억을 강화한다.
- Anki도 핵심 개념을 active recall testing과 spaced repetition 두 가지로 설명한다.
- 제품 적용:
  - 답을 바로 보여주지 않는다.
  - 사용자가 먼저 떠올리게 한 뒤 답을 공개한다.
  - 단순 객관식만이 아니라 `직접 입력`, `문장 완성`, `소리 내 말하기`도 후속으로 고려한다.

### 3. 피드백 있는 반복 인출
- Karpicke와 Roediger 연구는 반복 테스트가 장기 기억을 높이며, 피드백이 있는 테스트가 더 좋다고 본다.
- 제품 적용:
  - 틀린 뒤 바로 답만 보여주는 데서 끝내지 말고, 짧은 예문/발음/힌트를 제공한다.
  - 오답 직후 당일 재노출과 며칠 뒤 재노출을 분리한다.
  - `바로 다시 보기`와 `장기 복습 큐`를 구분한다.

### 4. 자신감 기반 평가
- Brainscape는 사용자가 답을 떠올린 뒤 1-5 자신감 점수를 매기고, 그 점수로 다음 노출 시점을 정한다.
- 제품 적용:
  - MVP는 `알고 있음`/`잘 모르겠음`으로 시작할 수 있다.
  - 고도화 시 버튼을 `모름`, `어려움`, `알겠음`, `쉬움`, `완전암기`처럼 세분화한다.
  - 또는 UI는 단순하게 유지하고 내부적으로 반응 시간, 반복 실패, 정답 입력 여부로 난이도를 추정한다.

### 5. 문맥 학습
- 단어는 단독 암기만으로는 실제 사용 능력으로 이어지기 어렵다.
- 연구와 사용자 경험 모두 단어를 문장, 상황, 말하기 과제로 연결해야 한다는 방향을 지지한다.
- 제품 적용:
  - 1단계: 단어 의미 암기
  - 2단계: 단어를 포함한 짧은 문장 해석
  - 3단계: 빈칸 문장 완성
  - 4단계: 특정 상황에서 단어를 사용해 직접 말하거나 쓰기

### 6. 섞어 풀기
- 비슷한 항목을 섞어 풀면 처음에는 어렵지만, 미묘한 차이를 구분하는 데 도움이 될 수 있다.
- interleaving 연구는 특히 유사 개념 간 구별이 필요한 학습에서 효과가 있다고 본다.
- 제품 적용:
  - 같은 뜻 계열, 헷갈리는 단어, 반의어, 시험 빈출 유사어를 묶어 비교 퀴즈를 낸다.
  - `affect/effect`, `accept/except`, `economic/economical` 같은 혼동쌍을 자동 생성하거나 교재에 포함한다.

## 외부 제품에서 가져올 수 있는 좋은 아이디어

### Anki
- 핵심: active recall + spaced repetition.
- 최근 Anki는 FSRS를 지원하며, 기존 SM-2보다 더 정교하게 잊을 가능성을 추정하는 방향이다.
- 가져올 점:
  - 카드별 복습 예정일.
  - 어려운 카드는 빨리, 쉬운 카드는 늦게.
  - 사용자가 오늘 볼 카드만 집중하게 하는 `오늘의 복습 큐`.
- 조심할 점:
  - 초보자에게 알고리즘과 설정이 어렵게 느껴질 수 있다.
  - 우리 제품은 Anki처럼 도구 중심이 아니라, 영어 교재와 코칭 중심으로 쉽게 보여줘야 한다.

### Duolingo
- 핵심: 짧은 세션, streak, 개인화 복습, 게임성.
- Duolingo는 personalized practice에서 정확도와 spaced repetition을 이용해 복습할 단어/문법을 고른다고 설명한다.
- 가져올 점:
  - 짧고 부담 없는 매일 학습.
  - streak, 알림, 캐릭터 반응.
  - 틀린 문제를 같은 세션 말미 또는 이후에 다시 묻기.
- 조심할 점:
  - 게임 점수만 올리고 실제 학습은 약해지는 `게임화 부작용`이 생길 수 있다.
  - 병맛 요소는 학습을 방해하지 않고, 학습 복귀를 유도하는 정도로만 써야 한다.

### Brainscape
- 핵심: confidence-based repetition.
- 사용자가 답을 떠올린 뒤 자신감 점수를 매기고, 그 점수에 따라 카드가 다시 나온다.
- 가져올 점:
  - `알고 있음`보다 더 섬세한 자기평가.
  - 사용자가 자기 기억 상태를 인지하게 하는 메타인지.
- 제품 적용 후보:
  - 초급 모드: O/X
  - 고급 모드: 1-5 자신감
  - 선생님/교재 모드: 정답률 + 자신감 + 반응 시간 종합

### Memrise
- 핵심: 단어 암기 + 실제 네이티브 영상/문맥 + 게임형 테스트.
- 가져올 점:
  - 단어를 실제 표현과 연결한다.
  - 단어 암기 후 문장/상황으로 확장한다.
  - 공식 교재와 사용자/커뮤니티 콘텐츠를 나눌 수 있다.

### Quizlet
- 핵심: flashcard, Learn/Test/Match 같은 여러 학습 모드, teacher assignments, class progress.
- Quizlet Assignments는 선생님이 학습 모드를 과제로 지정하고 그룹 진행률을 볼 수 있게 한다.
- 가져올 점:
  - 선생님용 과제 생성.
  - 학생별 진행률.
  - 반 전체가 많이 틀리는 단어 보기.
  - 로그인 없이 링크/코드로 참여하는 가벼운 수업 흐름.

### Kahoot / Gimkit / Blooket
- 핵심: 실시간 게임, 수업 참여, 리포트, 재미.
- Kahoot은 게임 후 리포트와 참여/정확도 추적을 제공한다.
- Gimkit은 과제를 내고, 결과를 반별로 볼 수 있다.
- Blooket은 게임 후 상세 리포트와 다양한 게임 모드를 강조한다.
- 가져올 점:
  - 같은 단어 세트를 게임처럼 풀기.
  - 반 전체 실시간 퀴즈.
  - 학생별/문항별 오답 통계.
  - 재미있는 모드와 진지한 리포트를 분리.

## 제품 방향 제안

### 방향 A. 개인 암기 코치
- 사용자는 단어장을 만들거나 가져온다.
- 앱은 오늘 외울 단어와 다시 볼 단어를 자동으로 고른다.
- 사용자는 매일 짧은 세션만 수행한다.
- 목표:
  - 단어를 잊기 직전에 다시 보여주기.
  - 오래된 단어를 가끔씩 섞어 장기 기억을 점검하기.
  - 자주 틀리는 단어를 오답노트로 관리하기.

### 방향 B. 영어 암기 교재 플랫폼
- 단어장을 단순 파일이 아니라 `교재`로 다룬다.
- 교재는 단원, 목표 단어, 예문, 퀴즈, 복습 스케줄, 테스트로 구성된다.
- 교재 제작자는 판매용 콘텐츠를 만들 수 있다.
- 사용자는 교재를 구매하거나 구독하고, 앱은 교재의 학습 흐름을 자동으로 운영한다.
- 목표:
  - `TOEIC Day 1`, `여행 영어 100문장`, `중학생 필수 영단어` 같은 판매 가능한 구조.

### 방향 C. 동료/그룹 학습
- 같은 교재를 공부하는 사람들을 그룹으로 묶는다.
- 서로의 전체 점수보다 `오늘 공부함`, `복습 완료`, `많이 틀린 단어` 정도를 공유한다.
- 특정 상황을 주고 영어로 답하는 미션을 낸다.
- 예:
  - 상황: 공항에서 여권을 잃어버렸다.
  - 목표 단어: passport, lost, help, embassy
  - 과제: 위 단어를 써서 영어로 한 문장 말하기.

### 방향 D. 선생님/반 관리
- 선생님이 교재 또는 단어 세트를 반에 배포한다.
- 학생들은 링크/코드로 참여한다.
- 선생님은 다음을 본다.
  - 학생별 학습 진행률
  - 오늘 학습 여부
  - 단어별 정답률
  - 반 전체가 많이 틀린 단어
  - 한참 뒤 재시험 결과
- 목표:
  - 학원, 학교, 스터디 그룹에서 사용할 수 있는 B2B/B2B2C 모델.

## 병맛/재미 요소 아이디어
- 확장 아이콘이 사용자의 복습 상태에 따라 변한다.
  - 오늘 복습 전: 잠 덜 깬 아이콘
  - 복습 미루는 중: 삐진 아이콘
  - 며칠째 안 함: 먼지 쌓인 아이콘
  - 복습 완료: 반짝이는 아이콘
- 단, 강압적이거나 죄책감을 주는 표현은 피한다.
- 학습을 망치는 과도한 게임화도 피한다.
- 병맛 요소는 `복귀 유도`, `짧은 웃음`, `캐릭터성` 정도로 제한한다.
- 예:
  - "나 오늘도 버려진 거야?"
  - "5개만 풀면 내가 조용해질게."
  - "passport가 너 찾고 있음."
  - "한 달 전 단어들이 지하에서 올라왔습니다."

## 좋은 아이템 후보

### 1. 오답노트가 살아 움직이는 시스템
- 틀린 단어는 오답노트에 들어간다.
- 하지만 오답노트에 고정 저장만 하지 않고, 정해진 시간 뒤 자동으로 다시 나타난다.
- 틀린 횟수와 마지막 실패일에 따라 `집요함`이 달라진다.

### 2. 한 달 전 단어 습격
- 사용자가 최근 단어만 기억하는 문제를 해결하기 위한 기능.
- 매일 세션에 과거 단어를 소량 섞는다.
- Chrome 확장에서는 갑자기 "한 달 전 단어 3개만 확인" 같은 미니 퀴즈를 띄운다.

### 3. 단어에서 문장으로 진화
- 단어를 2-3회 맞히면 다음 단계로 넘어간다.
- 다음부터는 단어 뜻만 묻지 않고 예문 빈칸, 상황 대답, 짧은 말하기를 낸다.
- 예:
  - 1단계: passport -> 여권
  - 2단계: I lost my ____.
  - 3단계: 공항 직원에게 여권을 잃어버렸다고 말하기.

### 4. 같은 교재 동기 그룹
- 같은 교재를 공부하는 사용자를 자동으로 약한 그룹으로 묶는다.
- 개인 정보는 노출하지 않고, 진행률과 오늘 학습 여부만 공유한다.
- 같은 단어를 두고 짧은 상황형 질문을 같이 푼다.

### 5. 선생님용 반 리포트
- 선생님은 교재를 반에 배포한다.
- 학생들은 앱/웹/확장으로 공부한다.
- 선생님은 반 전체가 취약한 단어와 학생별 학습 상태를 본다.
- 과제형, 실시간 게임형, 장기 복습형 리포트를 분리한다.

### 6. 교재 판매/구독 모델
- 교재 제작자는 단어, 예문, 퀴즈, 복습 정책이 포함된 `암기 교재`를 만든다.
- 사용자는 교재를 구매하고 앱에서 자동 스케줄에 따라 학습한다.
- 선생님/학원은 반 단위로 라이선스를 구매할 수 있다.

### 7. AI 교재 제작 보조
- AI가 단어 후보, 예문, 빈칸 문제, 상황형 질문을 생성한다.
- 사람은 검수하고 판매용 교재로 다듬는다.
- AI는 학습 중에도 사용자가 자주 틀리는 단어를 바탕으로 새 예문을 만든다.

## 우선순위 제안

### 1차 고도화
- 기존 `알고 있음`/`잘 모르겠음` 기록을 복습 스케줄로 연결한다.
- 카드별 `nextReviewAt`, `reviewCount`, `wrongCount`, `interval`을 추가한다.
- 오늘 복습 큐를 만든다.
- 오답노트와 오래된 단어 재출제를 만든다.

### 2차 고도화
- 단어 -> 예문 -> 문장 완성 흐름을 만든다.
- 답변 난이도를 2단계에서 4단계로 확장한다.
- Chrome 확장에서는 오늘 복습 큐 중 일부만 가볍게 노출한다.
- 병맛 아이콘/캐릭터 반응을 넣는다.

### 3차 고도화
- 교재 구조를 도입한다.
- 단원, 레슨, 목표 단어, 예문, 퀴즈, 복습 정책을 묶는다.
- 교재별 진행률과 판매/배포 구조를 검토한다.

### 4차 고도화
- 그룹/반 기능을 만든다.
- 선생님 과제, 반 리포트, 학생별/단어별 취약점 분석을 만든다.
- 같은 교재를 공부하는 사용자끼리 상황형 말하기/쓰기 미션을 제공한다.

## 당장 ChatGPT와 더 논의할 질문
- 우리 제품은 Anki형 도구에 가까워야 하는가, Duolingo형 코치에 가까워야 하는가, 아니면 영어 교재 플랫폼에 가까워야 하는가?
- 첫 복습 알고리즘은 SM-2 계열로 시작할까, Leitner box처럼 단순하게 시작할까, 아니면 FSRS식 상태값을 염두에 둔 자체 모델로 갈까?
- 사용자는 버튼 2개를 좋아할까, 4개를 좋아할까?
- 단어를 몇 번 맞히면 문장 단계로 넘어가야 할까?
- 교재 판매를 목표로 한다면 단어장 데이터 구조를 어떻게 바꿔야 할까?
- 그룹 기능은 친구형, 같은 교재 익명 코호트형, 반/선생님형 중 무엇을 먼저 해야 할까?
- 병맛 캐릭터는 얼마나 적극적으로 개입해야 학습에 도움이 되고, 어디부터 방해가 될까?
