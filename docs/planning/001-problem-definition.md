# Problem Definition 001

## 이번 회차 목표
- `암기 어시스턴트`의 문제 정의 초안을 작성한다.
- 사용자가 왜 이 제품을 쓰는지와 첫 개발 범위를 정할 때 막히는 지점을 분리한다.
- 구현 전에 반드시 필요한 질문을 다음 회차 입력으로 남긴다.

## 이번 회차에서 확정한 것
- 이 프로젝트는 key/value 단어장을 기반으로 암기를 도와주는 웹 서비스를 목표로 한다.
- 첫 번째 핵심 사용자는 어학 단어 학습자다.
- 1차 제품은 웹 앱과 클라우드 저장을 우선한다.
- 단어장은 Markdown 형태로 import/export할 수 있어야 한다.
- 단어장은 여러 개를 관리할 수 있어야 한다.
- 단어 항목의 MVP 필수 필드는 `key`, `value`, `최근 조회한 날짜`다.
- 프로필의 학습일 지표는 누적 학습일이다.
- Markdown 포맷은 앱이 안정적으로 읽고 LLM이 쉽게 생성할 수 있는 구조를 우선한다.
- 단어 암기 기능은 key/value 방향을 바꿔가며 질문하고, 사용자가 빠르게 `알고 있음` 또는 `잘 모르겠음`으로 넘어가는 흐름을 가진다.
- 프로필/진행률 화면이 필요하다.
- AI 추천은 후속 기능으로 둔다.
- 음성 인식, Chrome 확장, Windows 앱, 모바일 앱은 후속 확장 후보로 둔다.

## 문제 정의
- 사용자는 외워야 할 정보를 단어장으로 가지고 있지만, 파일, 앱, 기기마다 흩어져 있어 반복 학습과 진행 상태 추적이 어렵다.
- 단순히 단어 목록을 저장하는 것만으로는 어떤 항목을 다시 봐야 하는지, 어느 정도 외웠는지, 며칠 동안 학습했는지 알기 어렵다.
- 따라서 이 제품은 Markdown 기반 단어장을 클라우드에 저장하고, key/value 암기 세션과 상태 추적을 통해 사용자가 매일 복습할 항목을 빠르게 처리하도록 돕는다.

## 핵심 가치
- 기존 Markdown 단어장을 버리지 않고 그대로 가져와 학습할 수 있다.
- 학습 중 버튼 조작을 최소화해 암기 흐름이 끊기지 않는다.
- 최근 조회한 날짜와 학습 이벤트를 기반으로 다음에 볼 항목을 고를 수 있다.
- 여러 단어장을 한 계정에서 관리하고, 이후 여러 클라이언트로 확장할 수 있다.

## 주요 사용자
- 1차 핵심 사용자: 어학 학습자
- 확장 사용자 후보: 시험 준비생, 개발/전문 용어 암기 사용자, 자기주도 학습자

## 가정
- 초기 사용자는 데스크톱 또는 모바일 웹에서 단어장을 만들고 학습한다.
- Markdown import/export는 사용자가 서비스에 lock-in된다는 불안을 줄이는 핵심 기능이다.
- 클라우드 동기화를 제공하려면 어떤 형태로든 사용자 식별 또는 계정이 필요하다.
- AI 추천은 유용하지만 비용, 품질, 개인정보 처리 정책이 필요하므로 MVP 이후에 다룬다.

## 비범위
- 이번 회차에서 실제 서비스 코드는 작성하지 않는다.
- 이번 회차에서 음성 인식, Chrome 확장, Windows 앱, 모바일 앱을 MVP로 확정하지 않는다.
- 이번 회차에서 AI 추천 모델, 결제, 관리자 화면을 확정하지 않는다.
- 이번 회차에서 spaced repetition 알고리즘을 세부 구현까지 확정하지 않는다.

## 위험과 미확정
- MVP는 어학 단어 학습자 중심이지만, key/value 구조를 범용 질문/답 암기까지 확장할 여지는 남긴다.
- Markdown 포맷이 표준화되지 않으면 import/export, 동기화, 충돌 해결 구현이 흔들린다.
- 클라우드 동기화는 인증, 백업, 충돌 처리, 삭제 정책을 함께 요구한다.
- 다중 플랫폼을 처음부터 모두 포함하면 MVP가 커져 개발 속도가 느려질 수 있다.
