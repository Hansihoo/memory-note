# Agent Decisions

- (template) Record backward-compatible default decisions here with date, context, and rationale.
- 2026-05-05: T13 teacher classes privacy default. Teacher classes are private. Creating a class makes the creator an active TEACHER. Added students start as PENDING and must accept before assignments are visible or their activity can be included. Teacher dashboards return aggregate assignment progress only, not per-student review details. Assignments can reference only the teacher's own wordbooks, do not copy/delete/mutate student review state, and report zero-safe progress when no matching review data exists.
- 2026-05-05: T12 study groups privacy default. Study groups are private by default. Creating a group makes the creator an active OWNER. Added users start as PENDING members and must accept before their data is included. Group progress only aggregates active members' wordbooks that those same users explicitly linked to the group. Group weak-card detail returns only the requesting active member's own linked cards, so prompts/answers from other users are not exposed by default. Owner-only actions are member invite/removal; all group reads require at least membership, and progress/weak-card reads require ACTIVE membership.
- 2026-05-04: T4.5 profile 통계 호환 정책 적용. legacy learning_events 필드는 유지하고, review_logs/review_states 데이터가 있으면 우선 사용하되 중복은 memory_item_id > word_id > card_id 순서로 제거한다. API 응답 shape은 유지하고 확장 필드는 optional로 추가한다.
- 2026-05-04: T5.5 pending review queue 정책 반영. chrome.storage.local `pendingReviewQueue` 사용, 7일 보관/최대 200건 유지, flush 시 oldest-first 최대 20건 전송, 401/403은 큐 보존 후 중단, 404/409/422는 드롭, 네트워크/5xx는 재시도 카운트 증가.
- 2026-05-04: T6.1 MASTERED 정책 확정. REVIEW 상태에서만 interval_days>=30, streak>=5, lapses<=1, (difficulty 존재 시 <=0.7)일 때만 MASTERED 전환. difficulty가 null이면 차단하지 않음. MASTERED에서 AGAIN 시 RELEARNING/10분 due/lapses+1/streak=0/leech+2/last_reviewed_at 갱신, mastered_at은 유지.
- 2026-05-04: T6.2 장기 MASTERED 샘플링 정책 적용. /study/today에서 MASTERED 카드 장기 점검 슬롯을 limit의 10%(최소 1, 최대 limit)로 포함하고, 최근 7일 복습한 MASTERED는 제외, due된 MASTERED는 일반 due 카드로 처리. 정렬 우선순위는 last_reviewed_at(오래된 순) -> mastered_at -> card created/updated, 중복 카드 제외 및 memory_item 연속 최소화를 유지.
- 2026-05-05: T6.4 long-term memory stats 정책 적용. 기존 `/profile/summary` 응답 shape과 기존 필드 의미는 유지하고 장기 기억 통계는 optional 확장 필드(`masteredCount`, `longTermReviewCount30d`, `longTermCorrectCount30d`, `longTermRecallRate30d`, `masteredLapseCount30d`, `oldMasteredDueCount`)로만 추가한다. 기본 보고 기간은 최근 30일이며 review_logs/review_states를 우선 source of truth로 사용한다. `review_logs`는 삭제/변경하지 않고 null-safe 계산을 적용한다. 장기 리뷰 판정은 `state_before_json.status == MASTERED`를 우선하고, 값이 없을 때 안전하면 현재 `review_state.status == MASTERED`로 fallback한다. 같은 종류의 사소한 metric-definition ambiguity는 안전한 optional-field 기본값을 선택할 수 있으면 앞으로 hard blocker로 멈추지 않는다.
- 2026-05-05: T7 FSRS scheduler 도입 기본값. `SchedulerService.review(state, rating, reviewed_at)` 인터페이스와 기존 API 동작은 유지하고, 새 FSRS 계열 엔진은 `SCHEDULER_ENGINE=fsrs`로 선택할 수 있게 한다. 기본값은 backward-compatible하게 `simple`이며, 잘못된 값은 `simple`로 fallback한다. `retrievability`는 DB 컬럼으로 저장하지 않고 `ReviewState.last_reviewed_at`과 `stability`에서 계산한다.
- 2026-05-05: T8 word-to-sentence cards 정책 적용. 기존 Word API shape은 optional `exampleSentence`로만 확장한다. `WORD` 타입 memory_item에 예문이 있으면 기본 양방향 카드에 더해 `CLOZE`(예문 안 key/value 첫 일치 항목을 `____`로 치환, 없으면 예문+blank)와 `TYPING`(예문 prompt, key answer, value hint) 카드를 생성한다. 예문이 제거되거나 item type이 바뀌면 기본 생성 관리 대상 카드(`BASIC_*`, `CLOZE`, `TYPING`) 중 더 이상 원하는 카드가 아닌 것은 비활성화하되 review_logs는 유지한다.
- 2026-05-05: T9 Markdown v2 / course pack 기본 경계. Markdown v1(`key/value/lastViewedAt`)는 계속 호환하고, v2는 optional 컬럼(`itemType`, `exampleSentence`/`sentence`, `tags`, `cloze`)만 추가로 해석한다. `tags`는 comma/semicolon 구분 문자열로 받는다. `cloze`는 별도 학습 상태를 만들지 않고 예문 기반 CLOZE 카드의 metadata로만 보존한다. Course pack은 사용자 review state와 분리된 content-only 구조(`course_packs`, `course_units`, `course_lessons`, `course_lesson_items`)로 먼저 추가하며, 사용자 단어장으로 복사/시작하는 흐름과 권한/판매 정책은 후속 phase에서 다룬다.
- 2026-05-05: T11 study events 기본 정책. `study_events`는 review 이후 생성되는 append-only UX event log이며 review_logs/review_states의 source of truth를 바꾸지 않는다. 기본값은 `funEventsEnabled=true`이고, 사용자가 끄면 새 study_event를 생성하지 않는다. 이벤트 타입은 보수적으로 `MASTERED`, `MASTERED_LAPSE`, `LEECH`, `ZOMBIE_REVIEW`만 추가하며 API 응답 shape은 설정 endpoint와 optional user field로만 확장한다.
